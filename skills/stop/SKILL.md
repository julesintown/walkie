---
name: stop
description: Stops the Walkie. Use when the user wants to switch off or quit the walkie/companion.
---

Beende den Desktop-Begleiter mit `python3 "${CLAUDE_PLUGIN_ROOT}/cli.py" stop` (findet ihn auch,
wenn er aus einem anderen Ordner gestartet wurde) – und bestätige kurz.

Plugin folder: `${CLAUDE_PLUGIN_ROOT}`. If that variable is not set (e.g. in Codex), it is the folder two levels above this SKILL.md file.
